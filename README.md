# LIDEL — QarEra Trade Terminal

Eine klickbare Satire-Demo für den fiktiven QarEra-Handel von Ressourcen, Ausrüstung und Damage-Angeboten aus Gambia, inspiriert von der MU SmilingCoastBrigade.

## Starten
Die Website ist eine einzelne statische Datei: `index.html`. Lokal genügt es, die Datei im Browser zu öffnen.

## GitHub Pages aktivieren
1. Öffne **Settings → Pages** in diesem Repository.
2. Wähle bei **Build and deployment** die Option **Deploy from a branch**.
3. Wähle Branch **main** und Ordner **/(root)** und speichere.
4. Nach dem Build sollte die Seite unter `https://rololol.github.io/Lidel-WarEra/` erreichbar sein.

## Enthalten
- Responsive Dark-Terminal-Oberfläche
- Suche und Filter für Ressourcen, Ausrüstung und Damage
- Demo-Warenkorb mit Mengensteuerung
- Simulierter Checkout mit Demo-Bestellreferenz
- Satire-/Fiktionshinweis

## Grenzen
Dies ist eine **Frontend-Demo**. Es gibt kein echtes Konto, keine Datenbank, keine persistente Bestellung, keine Zahlung und keine Übertragung von Spielressourcen. Die Angebote und Preise sind erfunden. Eine Integration mit `app.warera.io` ist nicht eingerichtet; dafür wäre eine offiziell unterstützte API erforderlich.
